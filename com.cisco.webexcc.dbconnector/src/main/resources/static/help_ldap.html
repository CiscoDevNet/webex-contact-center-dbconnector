LDAP Management - Help Guide

Overview

The LDAP Management page lets you manage LDAP query endpoints that are exposed as API routes for Contact Center integrations.

Managing LDAP Statements

Adding a New Statement

Click "Add LDAP Statement" to create a new LDAP query endpoint. You will configure:

  • Name: Unique endpoint identifier used in the API path.
  • LDAP Connection: Directory connection where the query runs.
  • Base DN: Search base (for example, dc=example,dc=com).
  • Filter: LDAP filter string, with optional indexed placeholders like {0}, {1}.
  • Attributes: Optional comma-separated attribute list to return.

Available Actions

  • Edit: Update statement details.
  • Deploy: Promote DEV statements to higher environments.
  • Delete: Remove a statement.

Public Endpoint

Each statement is exposed at:

/api/ldap/query/{environment}/{name}

Tip: Validate filters and parameters with test values before promoting statements to UAT or PROD.
Important: Deploy actions should be reviewed carefully because they can overwrite existing statements in the target environment.
