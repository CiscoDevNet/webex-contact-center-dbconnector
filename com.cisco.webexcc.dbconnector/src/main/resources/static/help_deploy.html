Deployment - Help Guide

Overview

The Deployment pages allow you to promote tested endpoints from DEV to UAT or PROD. Deployment is supported for both SQL and LDAP endpoint types.

Supported Deployments

  • SQL Deploy: Promotes a DEV SQL statement to a target SQL database connection in UAT/PROD.
  • LDAP Deploy: Promotes a DEV LDAP statement to a target LDAP connection in UAT/PROD.
Important: Deploy actions are available for DEV endpoints and target only UAT/PROD connections.

How to Deploy (SQL or LDAP)

  1. Verify Source Information:
    • Review the Name, Description, and Source Environment shown at the top of the deploy page.
    • Confirm you selected the correct endpoint type (SQL or LDAP).
  2. Select Target Connection:
    • Use the dropdown menu to select a target UAT/PROD connection of the same type:
    • SQL deploy page shows SQL-compatible target connections.
    • LDAP deploy page shows LDAP-compatible target connections.
    • Note: Only configured connections appear. If missing, add them on the Connections page first.
  3. Deploy:
    • Click the Deploy button.
    • If a same-name endpoint already exists in the target environment, you will be prompted to Confirm Overwrite.

What Gets Copied

  • SQL: name, query content, parameter definitions, and target connection/environment.
  • LDAP: name, base DN, filter, attributes, parameter definitions, and target connection/environment.

Warnings & Confirmation

  • Overwrite Warning: If an endpoint with the same name already exists in the selected target environment, the system shows a warning.
  • Confirmation: You must confirm overwrite before the existing target endpoint is replaced.
  • Connection Type Safety: SQL deploy only accepts SQL connections; LDAP deploy only accepts LDAP connections.

Best Practices

  • Always validate endpoints in the Test Console before deploy.
  • Use clear endpoint names and keep DEV/UAT/PROD behavior aligned.
  • Ensure target connection credentials and network access are correct for the destination environment.
