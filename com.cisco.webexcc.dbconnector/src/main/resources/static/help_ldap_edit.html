Add/Edit LDAP Statement - Help Guide

Overview

This form creates or updates LDAP statements used by API endpoints for directory lookups.

Form Fields

  • Name: Endpoint identifier appended to /api/ldap/query/{environment}/{name}.
  • Description: Optional explanation for administrators.
  • LDAP Connection: Directory source used for the query.
  • Base DN: Search root DN (for example, dc=example,dc=com).
  • Attributes: Optional comma-separated attributes to return.
  • LDAP Filter: Query filter with optional placeholders such as {0} and {1}.

Parameter Placeholders

When placeholders are present in the filter, the page will generate parameter rows where you can map each index to a query parameter name and provide test values.

Testing

Use Test LDAP to validate the filter and connection before saving. Save stays disabled until a successful test run.

Tip: Keep filter names and parameters stable to avoid breaking API clients that consume this endpoint.
