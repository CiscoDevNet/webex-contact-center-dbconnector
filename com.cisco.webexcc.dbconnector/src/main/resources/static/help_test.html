Test Console - Help Guide

Overview

The Test Console allows you to execute both SQL and LDAP endpoints directly from the browser. This is useful for verifying endpoint behavior and response payloads before integrating them into your Contact Center flows.

Supported Endpoint Types

  • SQL Endpoints: Execute saved SQL statements against configured database connections.
  • LDAP Endpoints: Execute saved LDAP queries (base DN, filter, attributes) against configured LDAP connections.
API patterns shown in Test Console:
SQL: /api/query/{env}/{name}
LDAP: /api/ldap/query/{env}/{name}

How to Use

  1. Select an Endpoint:
    • Browse SQL and LDAP endpoints in the left sidebar.
    • You can use the search box to filter by name, environment, or database.
    • Click on an endpoint to load it into the main console area.
  2. Enter Parameters:
    • If the selected endpoint requires parameters, input fields appear in the "Request Parameters" panel.
    • SQL endpoints use configured statement parameter names from the SQL definition.
    • LDAP endpoints use configured parameter names that map to filter placeholders like {0}, {1}.
    • Enter valid test values for each parameter.
  3. Run Request:
    • Click the "Run Request" button.
    • The system executes the selected SQL or LDAP endpoint using its configured connection and environment.
  4. View Results:
    • The JSON response from the API will be displayed in the "Response Body" panel.
    • The status indicator will show if the request was successful (200 OK) or if an error occurred.
    • Responses can be an object (single result) or an array (multiple results).

Examples

  • SQL: /api/query/dev/get_customer?customerId=12345
  • LDAP: /api/ldap/query/dev/find_user?uid=einstein

Troubleshooting

  • Network Error: Check if the backend server is running and accessible.
  • 400 / Validation Error: Required parameters may be missing or invalid.
  • SQL Error: There may be an issue with SQL syntax, statement mapping, or DB credentials.
  • LDAP Error: Verify LDAP URL, bind DN/password, base DN, filter, and attributes.
  • Empty Response: The endpoint executed successfully but returned no matching rows/entries for the supplied parameters.
