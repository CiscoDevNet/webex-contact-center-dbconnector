Webex DB Connector

Enterprise-grade middleware for Webex Contact Center

v2.1.1

The Webex Contact Center DB Connector bridges Webex Contact Center flows with enterprise data systems by exposing secure, managed SQL and LDAP endpoints.

Secure Access

Connect to internal SQL databases and LDAP directories without exposing back-end systems directly.

SQL + LDAP Mgmt

Create and maintain SQL and LDAP endpoints through a unified admin experience.

Environment Mgmt

Promote endpoints from DEV to UAT/PROD with environment-aware connections and overwrite confirmation.

Test + REST APIs

Validate endpoint behavior in the Test Console and publish secure REST endpoints for flows.
